# Privacy

Claude Status Bar collects no data and has no servers. It runs entirely on your Mac. Its network activity is a once-a-day update check and, only if you turn on a usage metric, a once-a-minute request to Anthropic's usage API using your Claude Code login. The update check is one request to GitHub's public API for the latest release tag, and one to Homebrew's public formulae API for the current cask version, used only to show the update line in the menu. Nothing is sent to the developer (as with any update check or download, GitHub and Homebrew see the request; the developer never does).
